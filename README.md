# Todo List

A simple browser-based todo list app built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Clear completed tasks
- Persist tasks in browser local storage

## Run locally

Open `index.html` directly in your browser, or serve the folder locally:

```bash
cd "c:\Users\sarve\OneDrive\Desktop\git\todo_list"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project files

- `index.html` – app structure
- `styles.css` – styling
- `script.js` – todo logic
